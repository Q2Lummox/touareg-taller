# Taller 7L

Taller digital del VW Touareg 7L (2.5 R5 TDI · BAC): modelo 3D interactivo, fichas de piezas, mantenimiento, historial, documentación, averías, fusibles y gastos.

**Abrir la app:** https://q2lummox.github.io/touareg-taller/

## Instalar
- **Android (Chrome):** abre el enlace ▸ menú ⋮ ▸ *Instalar aplicación*.
- **iPhone / iPad (Safari):** abre el enlace ▸ botón Compartir ▸ *Añadir a pantalla de inicio*.
- **PC (Chrome / Edge):** abre el enlace ▸ icono de instalar en la barra de direcciones.

Después de la primera carga funciona sin conexión. Los cambios se sincronizan entre dispositivos cuando hay internet.

## Datos
Firebase Firestore (plan gratuito), con acceso solo para la cuenta de Google del propietario.

## Versiones
Cada versión es una *release* con su etiqueta (`v1.0.0`, `v1.1.0`, …). La app avisa sola cuando hay una nueva: menú **Taller ▸ Acerca de y actualizaciones**. Novedades en [CHANGELOG.md](CHANGELOG.md).
